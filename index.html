Project Clio

Clio is an internal video-production and channel-management tool operated by Sunny Patel. It helps identify highlights, cut and caption videos, prepare metadata, and deliver videos to authorized channels using YouTube API Services.

How it works

  1. Find source material and identify candidate moments.
  2. Use local transcription and optional Google Gemini review to select and edit clips.
  3. Preview and adjust cuts, or enable an explicitly configured automatic workflow.
  4. Queue uploads to selected channels with resumable delivery, pacing, cancellation and quota checks.

The production application is private. This documentation site does not provide access to the homelab, credentials, clips, or channel analytics. Clio is not currently offered as a public SaaS product.
